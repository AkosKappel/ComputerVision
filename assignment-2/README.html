Segmentácia s využitím informácií o farbách

Pri segmentácií som opäť začal s načítaním obrazu a jeho konverziou do farebného priestoru Lab, s hodnotami pixelov z rozsahu [0-1]. Ďalej som si z obrazu vybral malý región, ktorý obsahoval farbu buniek, ktoré som chcel vysegmentovať a vypočítal som priemernú farbu tohto regiónu

# Load the image
img = cv.imread(file)
float32_img = img.astype(np.float32) / 255.0

# Convert to Lab color space
lab_img = cv.cvtColor(float32_img, cv.COLOR_BGR2LAB)

# Define the region of interest and its average 'Lab' color
roi = lab_img[2365:2398, 1622:1646]
avg_color = np.mean(roi, axis=(0, 1))

# Convert region of interest to RGB for visualization
roi_rgb = cv.cvtColor(roi, cv.COLOR_LAB2BGR)[:, :, ::-1]
avg_color_rgb = np.mean(roi_rgb, axis=(0, 1))

Potom som išiel vypočítať delta lab hodnotu pre každý pixel z obrázku. Túto hodnotu som vypočítal ako euklidovskú vzdialenosť medzi Lab hodnotou farby daného pixelu a Lab hodnotou priemernej farby regiónu. Následne som vytvoril masku, ktorá obsahovala iba pixely, ktoré boli dostatočne blízko priemernej farbe regiónu. Masku som vytvoril cez threshold, pri ktorej som však nevedel pouźiť OTSU algoritmus, pretože výsledok nebol dostatočne dobrý. Preto som nakoniec nastavil vlastnú hodnotu pre threshold. Na nasledujúcom obrázku môžeme vidieť rozdiel medzi OTSU algoritmom a manuálnym nastavením thresholdu na hodnotu 15 pre obrázok HMRegistred.png.

# Calculate the delta Lab as euclidean distance for each pixel in the image
delta_lab = np.sqrt(np.sum(np.square(lab_img - avg_color), axis=2))

# Threshold the distance map
threshold = 20.0
mask = (delta_lab <= threshold).astype(np.uint8)

# Apply the mask to the original image
result = cv.bitwise_and(img, img, mask=mask)

Lokalizácia časti obrazu s použitím detektorov a deskriptorov

Pri lokalizácií som si najprv načítal 2 obrázky, jeden veľký a druhý malý, ktorý som chcel lokalizovať vo veľkom obraze. Tieto obrázky som potom previedol do šedotónového obrazu.

# Load the two images
lookup_img = cv.imread('images/Matching/lookup.tif')
patch_img = cv.imread('images/Matching/patch1.tif')

# Convert to grayscale
lookup_gray = cv.cvtColor(lookup_img, cv.COLOR_BGR2GRAY)
patch_gray = cv.cvtColor(patch_img, cv.COLOR_BGR2GRAY)

Na obrázkoch som skúšal rôzne kombinácie detektorov a deskriptorov. Kokrétne som vyskúšal použiť Harris, FAST a SIFT detektory s ORB a SIFT deskriptormi. Tu sú zobrazené niektoré výsledky týchto experimentov.

Z experimentov som zistil, že na našom datasete obrázkov funguje najlepšie kombinácia SIFT detektora a deskriptora. V kóde som použil nasledovný postup:

  1. Vytvoril som SIFT objekt
  2. Našiel som keypoints a descriptors pre oba obrázky
  3. Vytvoril som brute force matcher
  4. Použil som knnMatch metódu na zhodu deskriptorov
  5. Prefiltroval som zhody tak, aby som zachoval iba tie, ktoré boli dostatočne dobré
  6. Vykreslil som zhody, ktoré zostali po filtrovaní
# Create SIFT detector
sift = cv.SIFT_create()

# Find keypoints and descriptors
kp1, des1 = sift.detectAndCompute(lookup_gray, None)
kp2, des2 = sift.detectAndCompute(patch_gray, None)

# Match descriptors between images
matcher = cv.BFMatcher()
matches = matcher.knnMatch(des1, des2, k=2)

# Filter matches using the Lowe's ratio test
ratio_thresh = 0.5
good_matches = []
for m, n in matches:
    if m.distance < ratio_thresh * n.distance:
        good_matches.append(m)

# Draw good matches
h, w = max(lookup_img.shape[0], patch_img.shape[0]), lookup_img.shape[1] + patch_img.shape[1]
img_matches = np.empty((h, w, 3), dtype=np.uint8)
cv.drawMatches(lookup_img, kp1, patch_img, kp2, good_matches, img_matches, 
               flags=cv.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS)

Nakoniec som vypočítal homografickú maticu, ktorá transformuje súradnice z malého obrazu do súradníc veľkého obrazu. Vypočítaná matica mala tieto hodnoty:

[
    [ 3.53424816e-01,  3.52866056e-01,  1.35979625e+02],
    [-3.53470359e-01,  3.52544323e-01,  6.57400988e+02],
    [-1.40647852e-07, -1.31746484e-06,  1.00000000e+00],
]

Pomocou tejto matice som transformoval 4 vrcholy určujúce rohy malého obrazu do súradníc veľkého obrazu a danú oblasť som vyznačil modrým obdĺžnikom.

# Compute homography matrix
src_pts = np.float32([kp2[m.trainIdx].pt for m in good_matches]).reshape(-1, 1, 2)
dst_pts = np.float32([kp1[m.queryIdx].pt for m in good_matches]).reshape(-1, 1, 2)
matrix, mask = cv.findHomography(src_pts, dst_pts, cv.RANSAC, 5.0)

# Localize image patch in the lookup image
h, w = patch_img.shape[:2]
src_corners = np.float32([[0, 0], [0, h - 1], [w - 1, h - 1], [w - 1, 0]]).reshape(-1, 1, 2)
dst_corners = cv.perspectiveTransform(src_corners, matrix)

# Draw rectangle around the patch
img = cv.polylines(lookup_img.copy(), [np.int32(dst_corners)], True, 255, 3, cv.LINE_AA)

SIFT metódu som aplikoval aj na ďaľšie výseky z veľkého obrazu. Druhý výsek bol z rovnakej oblasti ako prvý, ale mal bledšie farby. Tretí použitý výsek bol z inej časti obrazu a bol aj rozmerovo väčší. SIFT algoritmus dokázal všetky tri výseky správne lokalizovať, čo môžeme vidieť na nasledujúcom obrázku.
