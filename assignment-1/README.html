3.2. Binarizácia

Metóda OTSU nebola pre tento obrázok vhodná, pretože spôsobovala problémy, najmä v pravej a dolnej časti obrázku, kde sa vytvorili čierne škvrny. Adaptívne prahovanie som si vyskúśal na všetkých štyroch rozmazaných obrázkoch a následne som si vybral najlepší výsledok, ktorým sa zdal byť obrázok rozmazaný pomocou metódy Gaussian Blur. Pri tomto obrázku sú hrany najvýraznejšie a na pozadí sa vyskytuje najmenej čiernych bodov.

Parametre pre funkciu cv2.threshold() sú nasledovné: * gray - vstupný obrázok * 0 - hodnota prahovania * 255 - maximálna hodnota prahovania * cv.THRESH_BINARY + cv.THRESH_OTSU - typ prahovania

Parametre pre funckiu cv2.adaptiveThreshold(): * gray - vstupný obrázok * 255 - maximálna hodnota prahovania * cv.ADAPTIVE_THRESH_GAUSSIAN_C - metóda adaptívneho prahovania (Gaussian alebo Mean) * cv.THRESH_BINARY - typ prahovania * 11 - veľkosť okolia, ktoré sa použije pri adaptívnom prahovani * 2 - konštantná hodnota, ktorá sa odčíta z výsledku adaptívneho prahovania

Metóda watershed

Pri tomto obrázku som si vyskúšal aj druhý spôsob na spočítanie buniek, a to metódu Watershed. Na začiatok som spravil OTSU thresholding na červenom kanáli a binarizovaný obraz som upravil morfologickými operáciami. Potom som oblasti obrazu rozdelil na tri regióny: pozadie, popredie a neznáma časť. Pozadie som zistil tak, že som na binarizovaný obraz aplikoval diláciu, aby som zvýšil plochy buniek, a pre pozadie som zvolil tie body, ktoré mali aj po dilácii hodnotu 0. Na zistenie popredia som použil funkciu cv2.distanceTransform(), ktorá vypočíta vzdialenosť od každého bodu k najbližšiemu bodu s hodnotou 0. Následne som na vypočítané vzdialenosti aplikoval funkciu cv2.normalize(), pomocou ktorej som normalizoval hodnoty do intervalu [0, 1] a pre popredie som zvolil tie body, ktoré mali hodnotu väčšiu ako 0.2. Ako neznámu časť som zvolil oblasti, ktoré neboli ani pozadie ani popredie. Potom som z detekovaného popredia vytvoril značky, ktoré som použil ako vstup pre funkciu cv2.watershed().

# Otsu's thresholding on red channel
_, otsu = cv.threshold(r, 0, 255, cv.THRESH_BINARY_INV + cv.THRESH_OTSU)

# morphological operations
kernel = cv.getStructuringElement(cv.MORPH_ELLIPSE, (3, 3))
opening = cv.morphologyEx(otsu, cv.MORPH_OPEN, kernel, iterations=2)

# find sure background area
sure_bg = cv.dilate(opening, kernel, iterations=5)

# create distance transform
dist = cv.distanceTransform(opening, cv.DIST_L2, 5)
cv.normalize(dist, dist, 0, 1.0, cv.NORM_MINMAX)

# find sure foreground area
_, sure_fg = cv.threshold(dist, 0.2 * dist.max(), 255, 0)

# find unknown region
sure_fg = np.uint8(sure_fg)
unknown = cv.subtract(sure_bg, sure_fg)

# marker labelling
_, markers = cv.connectedComponents(sure_fg)

# add one to all labels so that sure background is not 0, but 1
markers = markers + 1
# mark the region of unknown with zero
markers[unknown == 255] = 0

# apply watershed
markers = cv.watershed(img, markers)
watershed_img = img.copy()
watershed_img[markers == -1] = [0, 255, 0]

Parametre funkcie cv2.distanceTransform(): * image - vstupný obrázok * distanceType - typ vzdialenosti (cv2.DIST_L2, cv2.DIST_L1) * maskSize - veľkosť masky

Parametre funkcie cv2.normalize(): * src - vstupný obrázok * dst - výstupný obrázok * 0 - minimálna hodnota * 1.0 - maximálna hodnota * cv2.NORM_MINMAX - typ normalizácie

Parametre funkcie cv2.watershed(): * image - vstupný obrázok * markers - značky, ktoré určujú regióny, v ktorých sa nachádzajú bunky

Ako to môžme vidieť na dolnom obrázku, metóda Watershed nedosiahla podobne dobré výsledky ako predchádzajúca metóda. Hlavným problémom pri tejto metóde bolo to, že watershed rozdelil mnohé bunky na viacero menších častí a iné zase naopak, spojil do jedného veľkého celku. Pre zlepšenie výsledkov som skúsil zmeniť parametre na nájdenie poporedia a pozadia, ale nepodarilo sa mi získať lepšie segmentovaný obrázok, než ako pri metóde detekovania kontúr.
